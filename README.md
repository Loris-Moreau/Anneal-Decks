# Anneal-Decks

Generated study decks for [Anneal](https://github.com/Loris-Moreau/Anneal). Content only: no scheduling data, ever.

## Layout

```
decks/<deck-id>/meta.json     provenance, license, sha256 of the other two files
decks/<deck-id>/deck.jsonl    one card per line
decks/<deck-id>/graph.json    concepts and prerequisite edges
index.json                    generated by CI. Do not edit.
```

Each push to `main` that touches `decks/` validates every deck, regenerates `index.json`, and creates a tag and GitHub Release (`vYYYY.MM.DD-N`). Clients pin to a tag and read through jsDelivr:
`https://cdn.jsdelivr.net/gh/<owner>/Anneal-Decks@<tag>/index.json`

## Adding a deck

1. In the Anneal repo: `pnpm anneal wiki "Page title" --show`, read the cards, check `report.json`.
2. `pnpm anneal publish decks/wiki-page-title --to <path to this clone>`. It refuses decks that fail validation.
3. Commit and open a PR (or push to `main`). CI re-validates.

Request a deck or report a bad card with the issue forms.

## Licensing

Each deck states its license in `meta.json`. Decks derived from Wikipedia are CC BY-SA 4.0: attribute Wikipedia contributors (the `source` field links the page and revision) and share derivatives under the same license. Only open-licensed or public-domain sources are accepted here; decks from copyrighted books stay local.
