# Contributing

- Decks must come from `anneal publish`. Hand-edited decks fail the hash check.
- Fix a bad card by opening a card-error issue. Include the card id.
- Do not edit `index.json`. CI regenerates it and PRs that touch it are rejected.
- Sources: open-licensed or public domain only. No text copied from books or paywalled articles.
- One deck per PR keeps review quick.
